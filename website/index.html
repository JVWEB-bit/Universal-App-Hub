How the workspace works

  1. Add website URLs or supported app links to your library.
  2. Turn on Activate Workspace to show the floating Hub control.
  3. Open a shortcut from the dashboard, library, or Hub menu.
  4. Return to this tab or your previous Android app using normal navigation when the OS permits it.

The Hub is a launcher overlay, not an embedded copy of another app. State preservation depends on the browser, Android, and the destination app.

Install and connect

  1. Open the android/UniversalAppHub project in Android Studio.
  2. Build a debug APK or run the app on a physical device (recommended for overlay testing).
  3. Launch Universal App Hub on the device and read the overlay permission explanation.
  4. If you choose to continue, grant “Display over other apps” in Android settings.
  5. Turn on Activate Workspace in the companion. A movable Hub button appears when overlays are allowed.
  6. Open another supported app, tap the Hub, and choose a shortcut. Use Recents or Back to return when Android preserves the previous task.

This website stores preferences locally in your browser. The Android app stores its own workspace on the device. Secure cross-device sync is designed for a later release and is not active yet.

What the companion does

  • Launches supported installed applications with standard intents and deep links.
  • Shows a user-controlled floating Hub when overlay permission is granted.
  • Does not embed another app’s full interface inside the Hub menu.
  • Does not bypass overlay restrictions, capture other apps’ screens, or inject input.
